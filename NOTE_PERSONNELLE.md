# Note personnelle

Dans le cadre de ce projet Todo List, j’ai appris les bases des tests unitaires avec Jest, React Testing Library et Supertest.

J’ai appris à tester les composants React comme `TaskForm`, `TaskList` et `TaskItem`, ainsi que la fonction utilitaire `validateTask`. J’ai également appris à tester les différentes routes de l’API backend avec Jest et Supertest.

La principale difficulté rencontrée était de comprendre la configuration des tests et la communication entre le frontend React et le backend Node.js/Express. J’ai également rencontré quelques difficultés lors de la configuration de Jest et de la couverture de code.

Ce projet m’a permis de mieux comprendre l’importance des tests automatisés et de vérifier que les fonctionnalités de l’application fonctionnent correctement. J’ai obtenu 34 tests passants avec une couverture de code de 100 %.

Cette expérience me permettra d’aborder plus facilement les tests des modules réels du projet Cam2Drive.
